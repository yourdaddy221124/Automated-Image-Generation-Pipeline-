API & Webhook Documentation

Trigger the pipeline programmatically via standard REST HTTP POST requests.

Webhook Endpoint

POST /api/generate-and-dispatch

Request Body (JSON)

{
  "topic": "Cyberpunk cafe in neon Tokyo during rain",
  "style_preset": "Cinematic",
  "aspect_ratio": "16:9",
  "delivery": {
    "channel": "telegram",
    "recipient": "123456789"
  }
}

cURL Example Command

curl -X POST http://localhost:3000/api/generate-and-dispatch \
  -H "Content-Type: application/json" \
  -d '{
    "topic": "Futuristic cricket stadium at sunset",
    "style_preset": "Photorealistic",
    "aspect_ratio": "16:9",
    "delivery": {
      "channel": "telegram",
      "recipient": "123456789"
    }
  }'
